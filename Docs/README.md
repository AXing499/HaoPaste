## 当前版本

- 版本：`0.13.20`
- 运行要求：macOS 14+
- 构建环境：Xcode 15+，本项目在 Xcode 26.5 / macOS 26.5 上验证
- 分发形态：菜单栏驻留应用，Release `.app` + DMG
- 设置：原生设置窗口，支持自定义快捷键、登录启动、历史上限、按应用排除、备份迁移与清理
- 内容格式：文本、富文本 RTF/HTML、URL、代码/JSON、HEX、图片、单文件 / 多文件引用
- 预览与导出：`⌘Y` 快速预览图片 / 全文 / 颜色 / 文件，支持拖拽到其他应用
- 多选与合并：`⌘` / `⇧` 多选，文本按换行合并复制，文件作为 URL 列表复制
- 翻译：Google / Bing / DeepL 通道与 Azure / DeepL / 百度 / Google Cloud 官方 API，支持引擎优先级与自动回退
- 快捷翻译：全局 `⌥⌘T`、菜单栏、行内按钮、打开面板自动翻译最新记录、识图并翻译
- 剪贴板挂架：顶部从上方整体滑入、左右水平滑入；支持动态卡片高度、双向滚动、不限加载数量、回形夹点击删除、预览 / 翻译就地浮出、右键菜单与拖拽导出
- 识图：Vision 本地文字识别，支持单张 / 批量、语言选择、本地缓存与翻译
- 搜索：中文、拼音全拼 / 首字母缩写、模糊匹配、相关性排序
- Snippets：常用文本片段，面板快速复制，随备份导出
- 运行时依赖：无第三方库
- 质量：116 个 XCTest + GitHub Actions CI
- 本地化：跟随系统语言的中文 / 英文界面，资源位于 `HaoPaste/en.lproj` 与 `HaoPaste/zh-Hans.lproj`
- 英文 README：仓库根目录 `README.en.md`
