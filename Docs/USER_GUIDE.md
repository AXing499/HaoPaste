# 用户指南

> HaoPaste 是一个菜单栏驻留的 macOS 剪切板管理器。它没有 Dock 图标，也不要求登录账号；安装后从菜单栏或全局快捷键使用。

## 1. 安装

### 方式 A：DMG（推荐给日常使用）

1. 打开 `dist/HaoPaste-0.15.0.dmg`（仓库开发目录中，执行 `make dmg` 生成），按窗口中的安装提示将 HaoPaste 拖入 Applications。
2. 将左侧的 **HaoPaste** 拖入右侧的 **Applications / 应用程序** 文件夹。
3. 从“应用程序”、Launchpad 或 Spotlight 启动 **HaoPaste**。
4. 首次启动会自动展示一次面板；之后它会驻留在菜单栏。
5. 首次打开如提示「无法验证开发者」：打开「系统设置 → 隐私与安全性」，在「安全性」中找到 HaoPaste，点击「仍要打开」；也可以在 Finder 中右键 HaoPaste → 打开。

### 界面语言

- 默认跟随系统：中文环境显示简体中文，英文环境显示英文，其他语言环境默认英文。
- 设置 → 通用 → 应用语言可手动选择「跟随系统 / 简体中文 / English」。
- 更改语言后点击「立即重启」；应用会重新启动并应用新语言。

### 方式 B：命令行安装

```bash
make install
```

脚本会构建 Release 版本，并安装到 `/Applications`；如果该目录不可写，则安装到 `~/Applications`，随后自动启动。

### 不需要 Xcode 才能使用

终端用户只需要 `.app` / `.dmg`。Xcode 仅用于开发、调试与重新打包。项目已经提交了 `HaoPaste.xcodeproj`，开发者也可以直接打开它。

## 2. 启动与退出

### 启动

- 从“应用程序”双击 **HaoPaste**；
- 或在 Spotlight 中搜索 **HaoPaste**；
- 或点击菜单栏中的剪贴板图标。

HaoPaste 的 `LSUIElement = true`，因此**不会出现在 Dock**。启动成功的标志是系统菜单栏中出现剪贴板图标。

首次启动时面板会自动弹出一次。若没有看到，可从菜单栏图标打开，或按 `⌥⌘V`。

### 呼出面板

| 操作 | 行为 |
| --- | --- |
| `⌥⌘V`（默认，可在设置中修改） | 全局呼出 / 收起悬浮面板 |
| 左键点击菜单栏图标 | 呼出 / 收起 |
| 右键点击菜单栏图标 | 打开功能菜单 |

### 顶部剪贴板挂架

- 把鼠标移到所选屏幕边缘的中间三分之一区域，挂架会在约 0.25 秒后展开；默认位置是顶部菜单栏
- 在 **设置 → 通用 → 剪贴板挂架 → 显示位置** 中可切换顶部 / 左侧 / 右侧；侧边模式为竖向挂架，超出屏幕后上下滑动查看
- 如果 Dock 放在左侧或右侧，触发区域可能被 Dock 占用，可改用另一侧
- 卡片高度会根据图片比例和文本片段长度自适应；图片按真实宽高比决定高度
- 顶部挂架从菜单栏上方整体滑入，左侧 / 右侧从屏幕边缘水平滑入；展开约 0.8 秒、收起约 0.6 秒
- 点击卡片立即复制到剪贴板，挂架不会关闭，方便连续复制；鼠标离开后约 0.5 秒自动收起
- 悬停卡片底部会出现操作条：预览、提取文字、翻译、置顶 / 取消置顶；点击金色回形夹会松开并删除该条内容
- 预览、提取文字和翻译弹框会在当前屏幕居中显示，并使用系统原生窗口阴影
- 图片卡片的「提取文字」只进行 OCR；翻译按钮在识图弹框内，不会自动消耗翻译额度
- 识图、翻译、片段等应用内生成的文本复制后也会进入剪贴板历史
- 挂架打开时，新复制的内容会以弹簧动效落入挂架；达到加载数量上限时也会平滑替换旧卡片
- 点击回形夹删除卡片时，夹子先松开并留在线上，卡片像纸片一样旋转向下滑落并淡出，随后夹子再单独掉落；卡片下落时长默认 0.75 秒，可在设置 → 通用 →「剪贴板挂架」中调整
- 悬停预览、提取文字、翻译、置顶按钮、主面板行内操作、回形夹和分类标签时会显示手型光标；主面板打开即生效
- 删除后新出现的卡片会使用全新的夹子状态，不会继承上一条的释放状态
- 侧边卡片最大高度限制为 200pt，卡片内容按实际高度布局，长卡片不会溢出压住下一张卡片
- 顶部和侧边都取消了卡片基础旋转；顶部夹子线环正对晾衣绳，侧边恢复靠边竖轨 + 短臂，短臂穿过夹子线环
- 卡片较多时，滚动条只在滚动时出现，平时不会遮挡或干扰挂架
- 预览、提取文字和翻译会在挂架旁直接浮出，不会跳转到主面板；右键卡片还可复制、复制纯文本、删除，以及打开链接 / 文件、在 Finder 中显示、保存图片、复制 Markdown 链接或颜色格式
- 按住文本、图片或文件卡片拖到其他应用，即可直接导出；多文件条目可拖动文件图标一次拖出全部文件
- 底部可切换「全部 / 文本 / 图片」；「文本」同时包含代码、链接和颜色
- 加载数量可设为 6 / 8 / 10 / 12 / 不限；超出屏幕后，顶部左右滑动、左侧 / 右侧上下滑动查看，并显示滚动指示
- 可在 **设置 → 通用 → 剪贴板挂架** 开启 / 关闭挂架、切换显示位置和加载数量
- 右键菜单栏图标 →「显示剪贴板挂架」可手动打开或收起
- 全屏应用、HaoPaste 自身在前台，或正在打开菜单栏菜单时不会自动展开
- 挂架只复制，不自动粘贴，因此同样不需要辅助功能权限

### 退出

- 右键菜单栏图标 → **退出 HaoPaste**；
- 或按 `⌘Q`（面板处于焦点时）；
- 退出后应用不再监听剪贴板。

## 3. 面板快捷键

| 快捷键 | 行为 |
| --- | --- |
| `↑` / `↓` | 切换选中条目 |
| `⇧↑` / `⇧↓` | 从锚点扩展多选范围 |
| `⌘⇧A` | 全选当前结果 |
| `↵` | 复制选中条目；多选时合并复制并关闭面板 |
| `⌘1` – `⌘9` | 复制当前结果中的对应条目 |
| `⌘P` | 置顶 / 取消置顶 |
| `⌘Y` | 打开 / 关闭选中条目的预览 |
| `⌥⌘T` | 全局翻译当前剪贴板文本（可在设置中修改） |
| `⌘T` | 翻译选中文本；图片上打开识图；翻译面板中按 `⌘T` 关闭 |
| `⌘R` | 识别选中图片中的文字 |
| `⌘⌫` | 删除当前选中条目 |
| `esc` | 多选时先取消多选；有搜索词时清除搜索；否则关闭面板 |
| `⌘W` | 关闭面板 |
| `⌘A` / `⌘C` / `⌘V` | 搜索框内的原生全选 / 复制 / 粘贴 |

> 复制只会写入系统剪贴板，不会自动粘贴到上一个应用，因此核心剪贴板功能不需要辅助功能权限。回到目标应用后按 `⌘V` 即可粘贴。可选的「划词翻译」在启用时需要辅助功能权限。

## 4. 设置

打开方式：

- 右键点击菜单栏图标 → **设置…**
- 或在 HaoPaste 有窗口焦点时按 `⌘,`

### 通用

- **登录时自动启动**：使用 `SMAppService` 注册为登录项。若系统要求批准，会显示“打开系统登录项设置…”按钮。
- **全局快捷键**：点击快捷键控件后直接按下新的组合键。必须包含至少一个 `⌘`、`⌥` 或 `⌃`；`esc` 取消录制。若新快捷键已被其他应用占用，HaoPaste 会提示并恢复为之前的快捷键。
- **监听剪贴板**：可以临时暂停 / 恢复监听，暂停期间不会记录新内容。
- **剪贴板挂架**：开启或关闭挂架，选择显示位置（顶部 / 左侧 / 右侧）与加载数量（6 / 8 / 10 / 12 / 不限）；默认开启、顶部加载 8 条。

### 历史

- **未置顶记录上限**：100 / 200 / 500 / 1000 条。置顶记录不占用上限，也不会被自动清理。
- **清空未置顶记录** / **清空全部记录**：清空全部会同时删除图片缓存，均需二次确认。
- **数据目录**：在 Finder 中显示 `~/Library/Application Support/HaoPaste/`。
- **备份与迁移**：
  - **导出历史**：将全部记录、置顶状态、来源应用、图片、富文本缓存与片段打包为 `.zip`。
  - **导入历史**：选择由 HaoPaste 导出的备份，合并到当前历史；相同内容自动跳过，导入的置顶状态会合并保留。
  - 导入受当前历史上限约束；超过上限时优先保留置顶，并按时间淘汰最早记录。
  - 备份包未加密，包含完整剪贴板内容、富文本缓存与片段，请妥善保管。
  - 文件条目只保存路径引用，备份不包含文件本体；迁移到另一台 Mac 后可能不可用。
  - 片段会随备份导入并自动合并。

### 翻译

- **快捷翻译**：在任意应用复制文本后按 `⌥⌘T`，无需打开主面板，翻译卡片会直接出现并自动翻译。
  - `↵` 复制译文并关闭，`⌘C` 复制译文并关闭，`esc` 关闭。
  - 翻译卡片内可以切换目标语言和引擎。
  - 右键菜单栏图标也可以选择「翻译剪贴板」。
  - 快捷键可在设置 → 通用 → 翻译中修改。
- **打开面板自动翻译**：设置 → 通用 → 翻译 →「打开面板时翻译最新记录」默认关闭。开启后只处理真正最新的文本，固定条目不会被误判为最新记录。
  - 只对新的、与目标语言不同的文本自动执行，每条记录只自动一次。
  - 图片、代码和与目标语言相同的文本不会自动翻译。
  - 不希望自动联网时关闭此开关即可。
- **行内操作**：悬停文本条目显示翻译按钮，悬停图片显示「提取文字」按钮；也可以按 `⌘T` / `⌘R`。
- **提取文字后再翻译**：图片预览的「提取文字」只做 OCR；识别完成后在识图窗口点击「翻译」再进入翻译面板。

### 智能

- **默认目标语言**：新翻译默认使用该语言；如果检测到原文已经是该语言，会在本次翻译中自动切换中英方向。
- **引擎优先级**：通过上下箭头调整顺序，翻译时按顺序尝试；某个引擎失败会自动回退到下一个。
- **官方 API 配置**：Azure 需要订阅密钥与区域；DeepL API 需要 Auth Key；百度需要 AppID 与密钥；Google Cloud 需要 API Key。保存后可点击「测试连接」。
- **凭证安全**：API Key 保存在 macOS 钥匙串，不会进入历史、日志或导出备份。
- **非官方通道**：Google、Bing、DeepL 无需配置，但没有公开契约，可能随时失效；请勿翻译敏感内容。
- **图片文字识别**：使用 macOS Vision 在本机完成，不上传图片；识别结果按图片与语言缓存在本机，可随时清除。
- **识别语言**：自动检测适合混合语言截图；也可固定中文（简体 / 繁体）、英语或日语以提高特定语种准确率。
- **识图缓存**：缓存位于数据目录的 `OCR/`，可在「清除识图缓存」中删除；默认不进入备份。

### 隐私

- **记录图片**：关闭后，新复制的图片不会进入历史，也不会写入图片缓存；已有图片不会被删除。
- **排除的应用**：点击“添加应用…”从 `/Applications` 选择一个或多个应用。来自这些应用的新复制内容不会写入历史。
  - 排除只影响新内容，不会清理已记录历史。
  - 匹配优先使用应用 Bundle ID；没有 Bundle ID 时回退到应用名称。
  - 隐藏类型、临时类型和常见密码管理器的过滤始终开启。
- 修改排除列表后立即生效，无需重启。

### 复制行为

- 设置 → 通用 →「复制行为」可分别设置主面板复制后、挂架复制后保持展开、立即收起或延迟 0.6 秒收起。
- 「富文本只复制纯文本」开启后，复制富文本条目只写入纯文本，不带 RTF / HTML。
- 文本条目右键也提供「复制为纯文本」；该操作只写入纯文本，不会额外生成重复历史条目。

### 划词翻译（实验性）

- 设置 → 智能 → 划词翻译开启；默认关闭。
- 首次开启需要授予辅助功能权限；仅用于读取当前选中文本。
- 鼠标划词后显示翻译图标，点击图标才会翻译。
- 鼠标悬停在图标上时图标保持显示，移开后 2 秒再消失；悬停时会高亮并轻微放大。
- 翻译卡片显示在选区附近，不模拟 `⌘C`、不自动复制。
- 全屏应用、安全输入状态、隐私排除应用和 HaoPaste 自身不触发。
- 当前版本仅支持鼠标划词；键盘选择待后续版本。
- 应用使用 ad-hoc 签名；重新安装构建后，macOS 可能要求重新授予辅助功能权限。
- 官方翻译 API 凭证保存在钥匙串；重新安装 ad-hoc 构建后，macOS 可能要求一次钥匙串授权。划词翻译使用无提示读取，当前不可访问的官方引擎会自动跳过。

### 首次启动

- 第一次启动会显示欢迎引导，介绍菜单栏图标、⌥⌘V、边缘挂架和卡片操作。
- 关闭引导后会打开一次主面板；之后可通过快捷键或菜单栏图标呼出。
- 设置 → 关于 →「查看首次引导」可以再次打开。

### 检查更新

- 默认从 `AXing499/HaoPaste` 的 GitHub Releases 检查更新，无需手动填写地址。
- 启动时最多每 24 小时自动检查一次；设置 → 关于中也可以手动检查。
- 发现新版本会显示版本说明和「下载更新」按钮，优先打开 Release 里的 DMG，没有 DMG 时打开 Release 页面。
- 只打开下载链接，不会自动下载或替换安装。
- 也支持自定义 JSON 更新清单，格式见 `Docs/update-manifest-example.json`。

### 最近删除

- 删除的记录不会立即永久消失，会进入面板的「最近删除」标签。
- 默认保留 7 天，可在设置 → 历史 →「最近删除」中改为 1 / 7 / 30 / 90 天。
- 在「最近删除」中可以把记录恢复到历史，也可以彻底删除；到期记录会自动清理。
- 清空全部历史或清空未置顶记录仍然会直接永久删除，不进入「最近删除」。

### 片段

- **新建片段**：在面板「片段」标签点击「新建片段」，或在任意文本条目右键选择「保存为片段…」，填写名称与内容后保存。
- **编辑 / 删除**：在面板片段列表右键选择「编辑片段…」或「删除片段…」；设置 → 片段中也提供编辑 / 删除按钮。
- **面板访问**：打开面板后切换到「片段」标签，搜索标题或内容，使用方向键选择，按 `↵` 或 `⌘1–9` 复制。
- 片段不会写入剪贴板历史，也不占用历史上限。
- 备份包会一并包含片段。

### 关于

查看版本号、当前快捷键、隐私说明，以及退出应用。

## 5. 日常操作

- **搜索**：打开面板后直接输入，按内容、来源应用、类型或格式过滤。
  - 支持中文、拼音全拼（如 `ba` 匹配「把」）、拼音首字母缩写（如 `bfz` 匹配「把复杂」）。
  - 支持模糊子序列匹配和相关性排序；空格分隔多个关键词时需要全部命中。
- **分类**：全部 / 文本 / 代码 / 图片 / 文件 / 链接 / 片段。颜色值归入「文本」分类。
- **复制**：点击卡片主体，或使用方向键选中后按 `↵`。
- **预览**：悬停条目后点击眼睛按钮，或选中后按 `⌘Y`。图片按原始比例展示并带透明棋盘格；文本 / 代码显示完整内容并支持选择，富文本按 RTF / HTML 格式渲染；颜色显示大色块与 HEX / RGB / HSL；文件列出路径和缺失状态。
  - 预览中 `↑` `↓` 切换条目，`↵` 复制并关闭，`esc` 返回列表。
  - 图片可点击「保存…」导出 PNG，也可直接拖拽到其他应用。
- **拖拽导出**：把文本、图片或文件条目从列表直接拖到其他应用；多文件条目可拖动文件图标一次拖出全部文件；预览中的图片与文件行同样支持拖拽。
- **识图**：图片预览底部点击「提取文字」，或右键图片选择「提取文字…」，也可选中图片后按 `⌘R`。
  - 识别结果可编辑，支持复制文字、保存为片段或直接翻译。
  - 点击「翻译」会把当前编辑后的文字送入翻译面板，复用已配置的翻译引擎。
  - 图片本身不会上传；识别结果按图片内容与识别语言缓存在本机，重新打开无需再次识别。
  - **批量识图**：按住 `⌘` 选择 2 张以上图片，点击底部操作条的「识别文字」；可逐张编辑 / 复制 / 翻译，也可一次复制全部。
  - 支持截图、扫描图、设计稿等图片中的文字；暂不支持扫描 PDF。
- **翻译**：
  - 选中文本后按 `⌘T`，或在预览底部点击「翻译」，也可右键选择「翻译…」。
  - 翻译面板顶部可切换目标语言与引擎；支持 Google / Bing 非官方通道，以及 Azure、DeepL API、百度、Google Cloud 官方 API。
  - 首次在线翻译会询问是否允许发送当前文本；之后可在设置 → 智能中重新授权。
  - 译文支持复制译文、复制双语或保存为片段；翻译结果不会写入剪贴板历史。
  - 长文本会按段落分块翻译，并显示进度；翻译失败时可重试或切换引擎。
  - 非官方 Google / Bing 可能限流或失效；DeepL 非官方当前受服务端版本限制，建议优先配置 DeepL API 官方通道。
- **多选合并**：
  - 按住 `⌘` 点击条目切换多选，按住 `⇧` 点击选择连续范围；也可以使用 `⇧↑` / `⇧↓` 扩展，`⌘⇧A` 全选当前结果。
  - 选中 2 条以上后，列表底部会出现操作条；按 `↵` 或点击「合并复制」。
  - 文本 / 代码 / 链接 / 颜色按列表可见顺序用换行合并为纯文本；富文本条目也按纯文本合并。
  - 全部选中文件时复制多个文件 URL；文本与文件混合时，文件以路径形式附加到文本末尾。
  - 图片暂不支持合并，操作条会显示「图片暂不支持合并」并禁用按钮。
  - 合并结果不会写入历史；按 `esc` 或点击「取消」退出多选。
- **文件条目**：在 Finder 中复制一个或多个文件 / 文件夹，会生成「文件」条目；点击即可把文件 URL 复制回剪贴板，右键选择「在 Finder 中显示」可定位文件。文件被移动或删除后，条目会显示警告并无法复制。
- **富文本**：从浏览器、备忘录等复制的格式化文本会保留 RTF / HTML。右侧徽章显示「富文本 · N 字符」；点击默认按原格式复制，右键「复制为纯文本」可去掉格式。超过 2MB 的 RTF / HTML 会自动回退为纯文本。
- **置顶**：悬停卡片后点击图钉按钮，或右键选择「置顶」；也可以在键盘选中时按 `⌘P`。
- **删除**：悬停后点击垃圾桶，或右键选择「删除」。
- **右键菜单**：复制、置顶 / 取消置顶、删除，以及按内容类型提供的快捷动作：
  - 链接：打开链接、复制为 Markdown 链接。
  - 文件：打开、在 Finder 中显示。
  - 图片：预览、保存图片…
  - 颜色：复制规范 HEX、RGB 或 HSL 表示。
  - 任意条目：预览。
- **关闭面板**：点击面板之外的任意位置或切换应用会自动关闭；也可以按 `esc` 或 `⌘W`。多选时第一次 `esc` 只取消多选，不关闭面板。
- **暂停监听**：右键菜单栏图标 →「暂停监听」。暂停期间不会记录新内容。
- **清空记录**：右键菜单栏图标 →「清空未置顶记录」。置顶记录会保留。

## 6. 数据与隐私

| 项目 | 位置 |
| --- | --- |
| 历史记录 | `~/Library/Application Support/HaoPaste/history.json` |
| 片段 | `~/Library/Application Support/HaoPaste/snippets.json` |
| 图片原图 | `~/Library/Application Support/HaoPaste/Images/` |
| 图片缩略图 | `~/Library/Application Support/HaoPaste/Images/*-thumb.png` |
| 富文本缓存 | `~/Library/Application Support/HaoPaste/RichText/` |
| 识图缓存 | `~/Library/Application Support/HaoPaste/OCR/` |

- 数据只保存在本机；默认不发起网络请求。只有启用在线翻译并授权后，才会把当前待翻译文本发送给所选引擎。
- 翻译结果只存在于当前面板，不写入历史；API 凭证保存在 macOS 钥匙串。
- OCR 在本机执行，图片不会上传；识别文字缓存在 `OCR/` 目录，可在设置 → 智能中清除，默认不进入备份。
- 导出的 `.zip` 备份是明文压缩包，请勿分享给不可信的人。
- 忽略 `org.nspasteboard.ConcealedType`、Transient、AutoGenerated 及常见密码管理器的私有类型。
- 记录上限：未置顶默认 200 条，可在设置中调整；超出后自动淘汰最早的记录，置顶记录永不自动清理。
- 图片以 PNG 存储，列表只加载缩略图。

### 重置数据

1. 退出 HaoPaste；
2. 删除 `~/Library/Application Support/HaoPaste/`；
3. 重新启动。

### 清除首次启动状态

```bash
defaults delete com.hao.HaoPaste hasCompletedFirstLaunch
```

## 7. 卸载

1. 退出 HaoPaste；
2. 如果启用了“登录时自动启动”，先在 HaoPaste 设置中关闭，或在“系统设置 → 通用 → 登录项”中移除；
3. 将 `/Applications/HaoPaste.app`（或 `~/Applications/HaoPaste.app`）移到废纸篓；
4. 如需要，删除 `~/Library/Application Support/HaoPaste/` 和 `~/Library/Preferences/com.hao.HaoPaste.plist`。

## 8. 常见问题

**为什么没有 Dock 图标？**
HaoPaste 是 `LSUIElement` 菜单栏应用。请查看屏幕右上角菜单栏中的剪贴板图标。

**必须安装 Xcode 吗？**
不需要。Xcode 只用于开发。安装 DMG 后可直接启动；只有需要重新编译源码时才需要 Xcode。

**Spotlight 里为什么会有多个 `HaoPaste.app`？**
每个 `.app` 实体都会出现在搜索结果中，常见来源有三种：

- `/Applications/HaoPaste.app`：正式安装版（应该保留的那一个）；
- Xcode Debug 构建：位于 `~/Library/Developer/Xcode/DerivedData/.../Build/Products/Debug/`；
- 仓库 `dist/` 中的打包副本（当前版本已不再输出独立 app，只生成 DMG）。

日常使用请只保留 `/Applications` 版本。停止 Xcode 调试后，可用 `xcodebuild clean` 或清理 DerivedData，并从 Launch Services 注销 Debug 产物：

```bash
/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister \
  -u ~/Library/Developer/Xcode/DerivedData/<HaoPaste-...>/Build/Products/Debug/HaoPaste.app
```

**“Developer ID 签名”和“公证”是什么？**
- **签名**：使用 Apple Developer Program 的 Developer ID 证书为应用做密码学签名，证明“这个包来自某个开发者，且打包后未被篡改”。
- **公证（Notarization）**：把签名后的 app / DMG 上传到 Apple Notary Service 做自动化恶意软件扫描；通过后 Apple 返回一张票据，再用 `stapler` 钉到安装包上。
- Gatekeeper 在**其他 Mac**上打开来自互联网的下载时，会检查签名和公证票据。个人本机构建的 ad-hoc 签名应用无需公证。
- 公证不是 App Store 上架，也不代表 Apple 审核或推荐你的应用；它只是安全扫描。需要付费的 Apple Developer Program 账号。

**首次双击没有任何反应？**
确认菜单栏是否出现图标；不要只看 Dock。应用启动后先显示一次面板，之后需要按 `⌥⌘V`。如果被系统拦截，请见下一条。

**提示“无法验证开发者”怎么办？**
本安装包使用本地 ad-hoc 签名，未做 Apple 公证。可在 Finder 中右键 HaoPaste → **打开**，或前往“系统设置 → 隐私与安全性”允许打开。

**快捷键没有反应？**
打开 **设置 → 通用**，检查快捷键是否被其他应用占用；重新录入一个组合键即可。HaoPaste 会在注册失败时提示并保留之前的可用快捷键。

**剪贴板监听会记录密码吗？**
HaoPaste 会过滤标注了隐藏 / 临时类型的剪贴板内容以及常见密码管理器类型；但并非所有应用都会正确标注。请自行评估在敏感环境中的使用。
